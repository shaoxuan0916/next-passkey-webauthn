# Next Passkey WebAuthn v0.3.1

- The npm README now shows the install command, links to GitHub, and highlights the re-enrollment requirement for legacy users.
- The GitHub quickstart now includes examples for session handling, HTTPS rate limiting, and custom passkey UI.
- The browser client returns `PasskeyRequestError` for failed HTTP responses with non-JSON bodies, such as an HTML error page from a proxy. JSON errors still report the SDK error code.

Apps on v0.3.0 can upgrade in place. Users moving from v0.1.x or v0.2.x need a working sign-in or recovery method so they can re-enroll their passkeys. [Upgrade guide](https://github.com/shaoxuan0916/next-passkey-webauthn/blob/main/docs/quickstart.md#upgrading-from-01x-or-02x)
