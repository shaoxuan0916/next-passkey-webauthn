# Next Passkey WebAuthn

Add passkey sign-in and account settings to an existing Next.js App Router app with PostgreSQL. The SDK includes a route handler, SQL migration, and React components that work with your app’s accounts and sessions.

```sh
npm install next-passkey-webauthn
```

Requires Node.js 20 or later and the minimum Node.js version for your Next.js release.

[Setup guide and example app on GitHub](https://github.com/shaoxuan0916/next-passkey-webauthn#readme)

**Upgrading from 0.1.x or 0.2.x?** Existing users must re-enroll their passkeys. Confirm they have a working sign-in or recovery method before upgrading. [Upgrade guide](https://github.com/shaoxuan0916/next-passkey-webauthn/blob/main/docs/quickstart.md#upgrading-from-01x-or-02x)
